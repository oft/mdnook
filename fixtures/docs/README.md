# 欢迎来到 mdnook

给文档一个安静的角落。从一个目录出发，让散落的笔记、使用指南和项目文档变得井然有序。

> 文件始终留在本机。选一个文件夹，打开浏览器，就可以开始阅读。

## 从这里开始

左侧目录树帮你找到位置，中间文件列表展示当前目录，右侧阅读区会打开你选中的文档。浏览器的前进和后退同样可用。

- 阅读 [快速开始](./指南/快速开始.md)
- 了解 [链接与图片](./指南/链接与图片.md#本地图片)
- 打开 [示例项目目录](./项目示例/)
- 试试 [带空格的文件名](./指南/带%20空格.md)
- 阅读 [编码文件名示例](./指南/100%25%20完成%23记录.md)

## 常用命令

```bash
npx mdnook ./docs
mdnook . --port 9000
mdnook ./docs --no-open
```

## 你的文档空间

| 操作 | 说明 |
| --- | --- |
| 选择目录 | 文件列表立即切换到对应目录 |
| 选择 Markdown | 在右侧预览，列表持续可见 |
| 跟随相对链接 | 同步更新目录与选中的文档 |
| 刷新 | 重新读取本地目录和当前文件 |
| Ctrl / ⌘ + K | 快速定位文件筛选框 |

## 阅读清单

- [x] 打开本地文档目录
- [x] 跟随文档中的相对链接
- [ ] 为自己的项目写下第一篇说明

## 留下一点空间

好的文档值得慢慢读。你可以拖动文件列表与阅读区之间的分隔线，为长文留出更多空间；也可以切换到深色主题。
